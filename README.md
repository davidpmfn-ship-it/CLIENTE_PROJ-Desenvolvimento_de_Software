# Template de Engenharia de Software

Planilha padronizada para especificação de requisitos, modelagem UML e dicionário de dados: conecta o mapeamento de processos (BPMN) até a estrutura física do banco de dados relacional em um fluxo único e rastreável.

## Como usar

Baixe o arquivo `.xlsx` na raiz deste repositório ou visualize a estrutura completa diretamente pelo arquivo `.pdf`.

- `Contexto_Inicial`: metadados do projeto, sumário e declaração As-Is / To-Be.
- `Documentação`: RF, RNF, Matriz de Rastreabilidade, Casos de Uso, Classes, Sequência e Definition of Done (DoD).
- `Software`: Dicionário de Dados e espaços para os modelos Lógico e Relacional.
